# javascript-calculator-precourse
## 구현할 기능 목록
### App.js
- index.js와 함께 실행담당
- 제공된 Console API를 사용해 입력/출력 기능 구현 필요
- 입력받은 값을 문자열 덧셈 계산기에 넣어 계산 후 결과 출력
### StringParser.js
- 문자열 파서 : App.js를 통해 입력받은 문자열을 파싱해주는 기능
- 문자열 파싱 기능 : 구분자와 숫자포함 문자열을 구분한다
    - 커스텀 구분자가 있는 경우
    - 커스텀 구분자가 없는 경우
- 입력값 확인 필요
    - 입력값이 비었는지 확인
    - 구분자 및 숫자에 [0-9,:]와 커스텀 구분자 외의 값이 있는지 확인
    - 구분자만 있을 경우 확인
    - 잘못된 값을 입력할 경우 [ERROR] 메시지 반환기능
### AddCalculator.js
- 문자열 덧셈 계산기 : StringParser를 이용해 입력받은 문자열을 파싱하고 숫자만 더한다
- 더하기 기능 : 구분자를 제외한 숫자만 더한다
    - 빈 문자열의 경우 0을 반환
    - 파싱을 통해 구별한 구분자를 뺴고 숫자만 더한다
